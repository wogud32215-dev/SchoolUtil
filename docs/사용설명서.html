설치 전에 — 스마트 앱 컨트롤 끄기 Windows 11

SchoolUtil 설치 파일은 아직 Microsoft 서명이 없어서, PC에 스마트 앱 컨트롤이 켜져 있으면 «신뢰할 수 없는 앱»으로 막히는 경우가 있어요. 설치가 안 되거나 exe가 바로 닫히면 아래를 먼저 해 보세요.

메뉴가 아예 없으면 이 PC에는 해당 기능이 없는 버전일 수 있어요. 그때는 1. 설치하기의 SmartScreen «추가 정보 → 실행»만 하면 됩니다.

  1. 키보드 Windows 키를 누르고 검색창에 스마트 앱 컨트롤 입력 «최고의 매치»에 나오는 시스템 설정 항목을 선택
  2. 설정 화면에서 끄기를 선택 선택 후 변경 사항이 저장되면 창을 닫아도 됩니다
  3. 다시 SchoolUtil-Setup-x.x.x.exe 설치를 시도
꼭 읽어 주세요
«끄기»로 바꾼 뒤에는 Windows를 다시 설치하지 않는 한 스마트 앱 컨트롤을 다시 켤 수 없다는 안내가 Windows에 표시됩니다. 학교·개인 PC 정책이 있다면 IT 담당 선생님께 한번 여쭤 보시는 것도 좋아요.
설치만 되면 SchoolUtil 데이터는 평소처럼 PC에 저장됩니다. 보안 기능을 끈 것과 별개로, 앱 안의 비밀번호·API 키는 기존 안내처럼 암호화·별도 파일로 관리돼요.
시작 가이드

SchoolUtil,
이렇게 쓰면 편해요

바탕화면 한곳에서 시간표·급식·할 일을 모아 보는 작은 도구예요. 학교만 한 번 연결해 두면 급식·학사일정이 알아서 따라옵니다.

처음 설정은 3~5분이면 충분해요 · 예시는 이천제일고 기준

1 설치하기

Setup 파일만 실행하면 됩니다.

  1. SchoolUtil-Setup-x.x.x.exe 더블 클릭
  2. Windows가 «알 수 없는 앱»이라고 하면 추가 정보 → 실행 (서명 없는 설치 파일이라 자주 나와요. 그래도 안 되면 맨 위 스마트 앱 컨트롤 안내를 먼저 확인)
  3. 설치 끝나면 SchoolUtil 실행
알아두면 좋아요
창 X 버튼은 «끄기»가 아니라 트레이로 숨기기예요. 완전히 끄려면 작업 표시줄 옆 SchoolUtil 아이콘 → 종료.

2 이런 화면이에요

카드마다 역할이 달라요. 켜고 끄는 건 설정에서 자유롭게.

📅 달력 · 학사일정 🍱 오늘 급식 📋 시간표 · 할 일 🌤 날씨 · 시계 🔗 업무포털 (선택)
설정은 화면 맨 아래 톱니바퀴 (또는 제목줄 설정) → 왼쪽에서 탭 고르기
달력 × 할 일 — 마감일 있는 할 일은 달력 칸에 같이 보여요. 날짜를 누르면 그날 학사일정 + 할 일을 한곳에서 추가·완료할 수 있어요.

3 카드별로 이렇게 써요

학교 연동 없이도 쓸 수 있는 것부터, 연동하면 빛나는 것까지.

📅 달력

한 달 그리드에 NEIS 학사일정과 할 일(마감일)이 함께 표시돼요. 날짜 클릭 → 그날 일정·할 일 정리.

할 일 추가는 달력 날짜 창이 가장 편해요

✅ 할 일

구분(수업·담임·행정 등)·업무·기한 표로 보기. 체크하면 완료. 미완료는 마감일 순으로 정렬돼요.

목록이 비면 달력에서 날짜 눌러 추가

🍱 급식 · 📋 학사일정

학교 연동 후 NEIS에서 오늘 급식, 이번 달·오늘 학사일정을 가져와요. 달력에도 학사일정이 깔립니다.

설정 → 학교 연동

🕐 시계 · 🌤 날씨

현재 시각·요일. 날씨는 Open-Meteo(무료) — 지역 이름·위·경도는 학교 연동 탭에서 바꿀 수 있어요.

학교 연동 → 날씨

📆 시간표

칸에 직접 입력하거나, 컴시간으로 교사 시간표·교체 수업 반영. 빈 칸 (+)에서 «매주» / «이번 주만» 보정도 가능.

설정 → 학교 연동 (컴시간)

📝 메모

포스트잇처럼 여러 장. 색·글자 입력하면 자동 저장. 제목줄에 «메모 N장»으로 개수가 보여요.

카드에서 바로 입력

⏳ D-Day

시험·행사·방학까지 며칠 남았는지 D-n / D-Day로 표시. 제목·날짜 넣어 추가.

D-Day 카드 하단 입력

☀️ 제일 메이트

앱 켤 때 하루 한 번, 오늘 마감 할 일·시간표·급식·오늘 일정 등을 모아 보여줘요. 글자 크기·보일 항목은 설정에서.

설정 → 카드 → 제일 메이트

🔗 업무포털

나이스·에듀파인·교육청 포털·(선택) Brity 버튼. URL만 열기가 기본, 자동 로그인은 실험 기능.

설정 → 포털 (아래 6번 참고)

4 학교 연결하기 필수

급식·학사일정이 «우리 학교» 기준으로 보이려면 이 단계가 필요해요. 보통 API 키 없이 학교 검색만 하면 됩니다.

이천제일고 예시로 따라 해 보세요.

  1. 설정 → 탭 학교 연동
  2. 학교 검색에 이천제일고 입력 → 검색 → 목록에서 학교 선택 교육청·학교 코드가 자동으로 채워져요
  3. 날씨도 이천이면 지역 이름 이천으로 바꿔 두면 편해요 기본이 서울이면 온도가 달라 보일 수 있어요
  4. 맨 아래 설정 저장 꼭 누르기
  5. 설정 → 카드에서 «오늘 급식», «학사일정» 켜져 있는지 확인
잘 됐는지 보려면 → 급식에 오늘 메뉴가 보이거나, 학사일정에 이번 달 일정이 보이면 성공!
안 보이면? 설정 저장 눌렀는지, 학교를 다시 검색해 선택했는지 확인해 보세요.

5 컴시간 시간표 이천제일고면 꼭

NEIS 학교랑 컴시간 학교 코드는 서로 달라요. 같은 «학교 연동» 탭 아래에서 따로 맞춥니다.

  1. 컴시간 학교 검색 → 이천제일 → 경기 이천제일고등학교 선택
  2. 학급 이름 표기 → 제일고 ver 농업계 제일고는 학과·반 이름으로 보여요
  3. 교사 선택에서 본인 고르기 (이름이 김*처럼 가려져 있어도 정상)
  4. 자동 갱신 사용 켜 두기 + 지금 가져오기
  5. 설정 저장 → 카드 탭에서 «시간표» 켜기
학교 PC에서 컴시간이 막혀 있으면 «s2h9 프록시» 모드를 켜 볼 수 있어요. (비공식이라 학교마다 결과가 달라요.)

6 업무포털 · 자동 로그인 선택

나이스·에듀파인 버튼으로 바로 열 수 있어요. 안 써도 앱은 그대로 잘 돌아가요.

처음엔 이렇게만 (추천)

  1. 설정 → 포털
  2. 로그인 방식 → URL만 열기
  3. 교육청 → 경기 · 쓰는 포털 «카드에 표시» · 설정 저장
  4. 버튼 누르면 브라우저가 열리고, 인증서는 평소처럼 직접 로그인

자동 로그인도 써 보고 싶다면 (실험 기능)

Chrome·Edge·Whale + 저장해 둔 인증서 정보로 로그인을 시도해요. 잘 안 되면 언제든 «URL만 열기»로 돌아오면 됩니다.

  1. 로그인 방식 → 자동 로그인 시도 (실험)
  2. 브라우저·아이디·비밀번호 입력 → 설정 저장
  3. 테스트해 보기로 한번 확인 (로그는 설정에서 열 수 있어요)
비밀번호는 PC의 schoolutil-secrets.json에만 암호화 저장돼요. 백업 JSON에는 들어가지 않습니다.

7 꾸미기 · 배치 · 저장

취향대로 바꿔도 데이터는 그대로 남아요.

🎨 테마

밝기·글꼴·글자 크기·카드 밀도·투명도. 위젯 모드에서 바탕이 비치게 조절할 수 있어요.

설정 → 테마

🧩 카드 · 레이아웃

쓰지 않는 카드 끄기. 벤토·달력 중심·시간표 중심 등 프리셋으로 한 번에 배치. 카드는 드래그로 위치·크기 조절.

설정 → 카드

🖥 표시 · 위젯 모드

위젯 모드면 바탕화면 위에 카드만 얹어요(빈 곳 클릭 통과). 일반 창은 앱 창 전체. Windows 시작 시 자동 실행, 모니터 선택·화면 맞춤도 여기.

설정 → 표시

💾 백업 · 업데이트

설정·할 일 등을 JSON으로 보내기/불러오기. 저장할 때 자동 백업도 만들어요. 설치판은 업데이트 확인으로 새 버전 받기.

설정 → 백업 · 데이터 위치 표시
