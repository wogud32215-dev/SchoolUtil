> 예시 학교명은 **이천제일고** 기준이 많습니다. 다른 학교도 «학교 검색»만 바꾸면 같은 흐름입니다.

## 설치 전 준비 (Windows 11)

SchoolUtil 설치 파일은 **Microsoft 서명이 없어서**, **스마트 앱 컨트롤**이 켜진 PC에서는 설치·실행이 막히는 경우가 있습니다.

1. Windows 검색 → **스마트 앱 컨트롤** → 시스템 설정  
2. **끄기** 선택 후 저장  
3. `SchoolUtil-Setup-x.x.x.exe` 다시 설치  

![검색](assets/스마트앱컨트롤-검색.png) · ![끄기](assets/스마트앱컨트롤-끄기.png)

검색 메뉴가 없으면 해당 기능이 없는 Windows일 수 있습니다. 그때는 SmartScreen **추가 정보 → 실행**만 하면 됩니다.

## 설치 · 처음 실행

1. Setup exe 실행 → SmartScreen이면 **추가 정보 → 실행**  
2. 설치 후 SchoolUtil 실행  
3. **Chrome/Edge에서 localhost만 연 경우 저장이 안 됩니다.** 반드시 **Electron «SchoolUtil» 창**을 사용하세요.

**트레이 동작**

- 창 **X** = 종료가 아니라 **트레이로 숨김**  
- 완전 종료 = 트레이 아이콘 우클릭 → **종료**  
- 트레이 **더블 클릭** = 다시 앞에 보기

## 화면 구성 · 설정 여는 법

![설정 예시](assets/설정-예시.jpg)

| 구역 | 설명 |
|------|------|
| **제목줄** | 전화 아이콘(내선번호), 톱니(설정), 숨기기/최소화 |
| **카드 그리드** | 시계·날씨·달력 등 — **제목줄을 잡고** 드래그해 위치·크기 조절 |
| **설정 모달** | 제목줄 톱니 → 왼쪽 탭(테마, 카드, 표시, …) |

**표시 모드**

- **위젯 모드**: 바탕화면 위에 카드만 얹음. 카드 밖 클릭은 바탕화면으로 통과(Windows).  
- **일반 창**: 불투명 앱 창 전체.  

설정 → **표시**에서 전환합니다. 바꾸면 창이 다시 만들어질 수 있습니다.

## 카드(위젯) 한눈에

설정 → **카드**에서 켜고 끕니다. 꺼진 카드는 대시보드에 안 보입니다.

| 카드 | 하는 일 | 연동 |
|------|---------|------|
| **시계** | 현재 시각·요일 | 없음 |
| **날씨** | 온도·날씨 코드 · 상세(시간별·주간) | Open-Meteo |
| **급식** | 오늘·주간 NEIS 급식 | 학교 연동 |
| **달력** | 월간 그리드 + 학사일정 + 마감 할 일 | NEIS + 할 일 |
| **할 일** | 구분·업무·기한 표 | 없음 |
| **메모** | 포스트잇 여러 장 | 없음 |
| **D-Day** | D-n / D-Day | 없음 |
| **시간표** | 수동 격자 또는 컴시간 | 컴시간(선택) |
| **학사일정** | 이번 달·오늘 NEIS 일정 목록 | 학교 연동 |
| **업무포털** | 나이스·에듀파인 등 버튼 | 포털 설정 |
| **앱 바로가기** | exe·바로가기 실행 | 없음 |

레이아웃 **프리셋**(벤토, 달력 중심, 시간표 중심, 간결, 와이드 등)은 설정 → 카드에서 한 번에 바꿀 수 있습니다. 이후에도 카드를 드래그해 미세 조정하세요.

## 오늘 한눈에 (제일 메이트)

앱을 켤 때 **하루에 한 번** 짧게 모아 보여 주는 창입니다.

- **포함 가능 항목**: 할 일, 시간표, 급식, 달력 일정, D-Day, 메모, 날씨 등  
- **설정**: 카드 탭 → «오늘 한눈에» 켜기/끄기, 글자 크기, 항목별 on/off  
- **미리 보기**: 같은 탭의 «미리 보기»로 오늘 내용 확인  

오늘 표시할 내용이 없으면 창이 뜨지 않을 수 있습니다.

## 달력 · 할 일 · D-Day · 메모

### 달력

- NEIS **학사일정**과 **마감일이 있는 할 일**이 같은 달 칸에 표시됩니다.  
- **날짜 클릭** → 그날 학사일정·할 일을 한곳에서 보고, 할 일 추가·완료 처리.  
- 중요 표시·시간이 있는 일정도 달력에 반영됩니다.  

### 할 일

- **구분**: 수업, 담임, 행정 등 (아이콘·색으로 구분).  
- **기한**이 있으면 달력에도 표시되고, 목록은 마감 순으로 정렬됩니다.  
- 목록이 비어 있어도 **달력 날짜 창**에서 추가하는 편이 빠릅니다.  

### D-Day

- 시험·행사·방학 등 **목표 날짜**까지 남은 날짜.  
- 카드 하단에서 제목·날짜 입력 후 추가.  

### 메모

- 여러 장의 메모 카드. 글·색 변경 시 **자동 저장**.  
- 제목줄에 «메모 N장»으로 개수 표시.

## 시간표 · 컴시간

### 수동 시간표

- 월~금 × 교시 칸에 직접 입력.  
- **(+)** 보정: «매주 반복» 또는 «이번 주만» 수업명 넣기.  

### 컴시간 연동 (이천제일고 등)

NEIS 학교 코드와 **컴시간 학교 코드는 다릅니다.** 설정 → **학교 연동** 아래에서 따로 맞춥니다.

1. **컴시간 학교 검색** → 학교 선택  
2. **학급 이름 표기** (예: 제일고 ver)  
3. **교사 선택** (이름이 `*`로 가려져도 정상)  
4. **자동 갱신** + **지금 가져오기**  
5. **설정 저장** → 카드에서 «시간표» 켜기  

**교체 수업**이 반영되면 알림·모달로 안내할 수 있습니다. «s2h9 프록시»는 학교마다 결과가 다른 **비공식** 우회입니다.

## NEIS · 급식 · 학사일정

### 학교 연결 (필수)

1. 설정 → **학교 연동**  
2. **학교 검색** (두 글자 이상) → 목록에서 선택 → 교육청·학교 코드 자동 입력  
3. 선택 시 **날씨 좌표**도 학교 주소 기준으로 자동 채워질 수 있습니다.  
4. **설정 저장**  
5. 카드에서 **급식·학사일정·달력** 켜기  

**성공 확인**: 급식에 메뉴, 학사일정·달력에 학교 일정이 보이면 OK.

### API 키

- 많은 환경에서 **공용 키** 또는 **개인 NEIS 키**를 씁니다.  
- 개인 키는 PC에만 **암호화 저장**되며, 백업 JSON에는 넣지 않습니다.  
- 키 오류 시 NEIS 메시지가 카드에 표시됩니다.

## 날씨

- **Open-Meteo** 무료 API (키 불필요).  
- **학교 선택** 시 도로명 주소로 좌표를 자동 설정합니다.  
- **수동**: 설정 → 학교 연동 → «지역 검색»(동·역 이름) → 목록에서 선택.  
- 위·경도 숫자로 미세 조정 가능. **지역 이름**은 위젯에 표시되는 라벨입니다.  
- 날씨 카드에서 **상세**로 시간별·주간 예보를 볼 수 있습니다.  

---

## 내선번호

- 제목줄 **전화 아이콘** → 부서·건물·층별로 정리된 내선 목록.  
- **번호를 누르면** 클립보드에 복사됩니다.  
- **편집** → 항목 삭제, 하단 «수동 추가»(건물·층, 부서, 이름, 내선).  
- **검색**으로 이름·부서·번호 필터.  
- 처음 설치 시 학교 예시 내선이 들어 있으며, 수정 내용은 `schoolutil-data.json`에 저장됩니다.

## 앱 바로가기

- **앱 바로가기** 카드: 자주 쓰는 프로그램·바로가기를 버튼으로 실행.  
- 설정 → **표시**(또는 카드 관련)에서 **바로가기 추가** → 파일 선택.  
- exe, lnk 등 Windows에서 열 수 있는 경로.

## 업무포털 · Brity (선택)

### 처음엔 URL만 열기 (추천)

1. 설정 → **포털**  
2. **URL만 열기**  
3. 교육청·표시할 포털 선택 → **설정 저장**  
4. 카드 버튼 → 브라우저에서 평소처럼 인증서 로그인  

### 자동 로그인 (실험)

- Chrome/Edge/Whale + 저장 ID·비밀번호로 **시도**합니다.  
- **테스트해 보기**로 확인. 실패하면 URL만 열기로 되돌리세요.  
- 비밀번호는 `schoolutil-secrets.json`에만 저장 (백업 JSON 제외).  

### Brity 메신저

- 설정 → 포털 하단 **Brity** 섹션에서 opt-in.  
- exe 경로·인증서 라벨 등 — 학교 정책에 맞게 사용하세요.

## 설정 탭별 안내

| 탭 | 내용 |
|----|------|
| **테마** | 색 테마, 글꼴, 굵기, UI 밀도, 카드 질감·투명도, 강조 카드, «미리보기»로 설정 창 뒤 대시보드 peek |
| **카드** | 위젯 on/off, 오늘 한눈에, 레이아웃 프리셋·초기화 |
| **표시** | 위젯/일반 창, 모니터, 화면 맞춤, Windows 시작 시 실행, 전역 단축키, 앱 바로가기 목록 |
| **학교 연동** | NEIS 학교 검색, 컴시간, 날씨·지역 검색 |
| **업데이트 및 백업** | JSON 보내기/불러오기, 데이터 경로, 자동 백업 안내, 업데이트 확인 |
| **포털** | 나이스·에듀파인·교육청·Brity |
| **안내** | 단축키, **사용 설명서 열기**, GitHub |

**저장 규칙**: 테마 탭의 색·질감 등은 **누르면 바로 저장**됩니다. 그 외 탭은 **«설정 저장»**을 눌러야 반영됩니다.

## 백업 · 업데이트 · 데이터 위치

| 항목 | 위치·설명 |
|------|-----------|
| **주 데이터** | `%APPDATA%\SchoolUtil\schoolutil-data.json` |
| **비밀값** | `%APPDATA%\SchoolUtil\schoolutil-secrets.json` (백업에 없음) |
| **자동 백업** | 저장할 때 `schoolutil-data.backup.json`, 날짜별 day 파일 |
| **수동 백업** | 설정 → 보내기 / 불러오기 (JSON) |
| **업데이트** | 설치판: 상단 배너 또는 설정 → 업데이트 확인 (GitHub Releases) |

불러오기 전에 현재 상태는 자동으로 백업됩니다. API 키가 들어 있는 JSON 파일은 **다른 사람에게 공유하지 마세요.**

## 위젯 모드 · 단축키 · 트레이

| 입력 | 동작 |
|------|------|
| `Ctrl+Alt+D` | 위젯 숨기기 / 다시 맨 앞에 (핀 상태에 따라) |

위젯 모드에서 바탕화면 **맨 아래** 배치가 실패하면 상단 배너로 안내합니다. **숨기기**·트레이·비상 단축키로 항상 앱을 찾을 수 있습니다.

## 자주 묻는 문제

**저장이 안 돼요**  
→ Electron SchoolUtil 창인지 확인 (`npm run dev`로 뜬 창). 브라우저 탭만 열면 IPC가 없습니다.

**급식·학사일정이 비어요**  
→ 학교 검색·**설정 저장**·카드 on/off·NEIS 키 상태를 확인하세요.

**날씨가 서울로 나와요**  
→ 학교 다시 선택하거나 설정에서 지역 검색·좌표를 맞추세요.

**컴시간이 안 돼요**  
→ 학교 PC 방화벽·컴시간 접속 제한. s2h9 프록시는 학교마다 다릅니다.

**업데이트 후 설정이…**  
→ `appId`·데이터 경로가 같으면 덮어쓰기 설치 시 데이터는 유지됩니다. 문제 시 백업 JSON으로 복원.
